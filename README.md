# Ankit Kanaujiya — Portfolio

A simple, responsive personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in your browser.

## Portrait
Place the portrait image in the repository root as `ankit-photo.jpg`. The portfolio displays it directly to the left of the name without a frame or box.

## Publish
The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`. In the repository settings, go to **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The Pages source is configured for GitHub Actions. Each push to `main` triggers deployment; check the **Actions** tab for the result.
